BuildLang

A compiled language with a self-hosting compiler, 62 native programs and a SQL database engine, built from scratch in Rust.

# compile and run
$ buildc hello.bld && ./hello
Hello, BuildLang!

# the self-hosted compiler compiles itself
$ qcodegen codegen.bld > codegen.c
2,490 lines .bld -> 3,600 lines C

# a real database engine, written in buildlang
$ qdb app.db "SELECT name, dept FROM employees WHERE salary > 100000 ORDER BY name"
name   | dept
-------+-----
Harper | eng
Zain   | eng

What it does

Compiler
Rust-based, 80K lines. Lexer, parser, type checker (Hindley-Milner), SSA-based MIR, 8 backends. 507 tests, zero warnings.
Self-hosting
2,490 lines of BuildLang that compile BuildLang to C. Structs, closures, impl methods, Vec, include!(). Generates valid C for all 62 programs.
Database engine
SQL with JOIN, GROUP BY, HAVING, DISTINCT, indexes, WAL crash recovery, transactions. 4,600 lines.
62 programs
Near-complete coreutils: grep, sed, awk, sort, diff, patch, find, jq, calc, base64, markdown to HTML, and more.

Architecture

source.bld -> lexer -> parser -> type checker -> MIR -> C backend -> gcc/MSVC -> native
